# MAKA PERUVIAN FOOD — Prototipo web

Este paquete contiene un prototipo visual responsive pensado como referencia de implementación en WordPress + Elementor + Hostinger.

## Dirección de diseño

- Verde principal: `#2F5438`
- Verde profundo: `#173323`
- Fondo casi negro: `#0C1711`
- Dorado de marca: `#FFD679`
- Dorado fuerte: `#F6C94D`
- Crema: `#F4EFE2`

La identidad se inspira en el logo PNG transparente suministrado para el proyecto y en la carta facilitada. La geometría utilizada es una interpretación contemporánea de patrones andinos; no se presenta como un símbolo arqueológico Inca concreto.

## Estructura propuesta para Elementor

1. Header transparente / sticky
2. Hero con vídeo + overlay
3. Ticker de especialidades
4. Presentación / filosofía
5. Bloque protagonista del ceviche
6. Selección de platos
7. Carta editable por categorías
8. Historia / identidad Maka
9. Horarios y ubicación
10. CTA de pedido
11. Footer

## Elementor

Crear primero estos colores como Global Colors y después usar Container + Flexbox:
- Primary: #2F5438
- Secondary: #173323
- Accent: #FFD679
- Accent Strong: #F6C94D
- Light: #F4EFE2
- Dark: #0C1711

La carta NO debería subirse como una única imagen si se quiere SEO y edición sencilla. El PDF se conserva como descarga secundaria.

## Precios

El contenido de la carta editable del prototipo se basa en la carta PDF facilitada (2025). Las plataformas de delivery consultadas muestran precios actuales diferentes en algunos platos. Por eso, antes de publicar, conviene que el restaurante confirme los precios finales para sala, recogida y delivery.

## Importante: vídeos

Los dos vídeos suministrados contienen marca de agua de Shutterstock. Se han integrado únicamente como material de prototipo. Para producción deben sustituirse por vídeos con licencia o material propio del restaurante.

## Producción recomendada

- WordPress actualizado + PHP 8.3+
- Elementor
- Caché/optimización compatible con Hostinger
- WebP/AVIF para imágenes propias
- Vídeos en WebM/MP4 optimizados, con poster
- Lazy-load fuera del hero
- Schema LocalBusiness/Restaurant
- Botones de llamada, mapa y pedido
- SEO local para L'Hospitalet / Barcelona
- Política de privacidad, cookies y aviso legal
